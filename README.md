# Java OOP Programs – Intermediate & Advanced Level

## 📌 About the Project

This repository contains Java programs based on **Object-Oriented Programming (OOP)** concepts. The programs cover intermediate and advanced-level problems involving **classes, objects, fields, class variables, local variables, methods, conditions, and problem-solving algorithms**.

These programs are created as part of the **Foundations of Java Development** lab work.

---

## 🎯 Topics Covered

* Classes and Objects
* Instance Variables / Fields
* Class Variables (`static`)
* Local Variables
* Methods
* Constructors
* Conditional Statements
* Loops
* Encapsulation Basics
* Mathematical Calculations
* String Manipulation
* Array and Matrix Operations
* Problem-Solving Algorithms
* Object Comparison
* Static Counters

## 🛠️ Requirements

To run these programs, you need:

* **Java Development Kit (JDK) 21 or above**
* VS Code / Eclipse / IntelliJ IDEA
* Java Extension Pack (for VS Code)

---

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone <your-repository-link>
```

### 2. Open the Project

Open the downloaded folder in **VS Code** or any Java IDE.

### 3. Compile the Program

For example:

```bash
javac Calculator.java
```

### 4. Run the Program

```bash
java Calculator
```

Replace `Calculator` with the class name of the program you want to run.

## 💡 Example

For Q21 – Palindrome:

